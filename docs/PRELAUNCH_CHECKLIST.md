# Pre-Launch Day Checklist

This checklist tracks critical tasks that must be verified before making the repository public and announcing MarketMind.

## 48 Hours Before Launch
- [ ] demo.marketmind.ai deployed and tested
- [ ] GitHub Pages landing page live (docs/index.html)
- [ ] All API endpoints tested with curl
- [ ] Docker Compose verified on clean machine
- [ ] Discord server set up with all channels
- [ ] Discord bot invited and running
- [ ] Product Hunt listing submitted for review

## 24 Hours Before Launch
- [ ] All launch posts written and reviewed
- [ ] Twitter thread (10 tweets) ready
- [ ] HN "Show HN" post ready
- [ ] Reddit posts (4 subreddits) ready
- [ ] LinkedIn article ready
- [ ] Email blast ready in Beehiiv
- [ ] YouTube demo video uploaded (unlisted)
- [ ] Personal outreach DMs sent (50-100 contacts)

## Launch Day Morning
- [ ] Wake up at 04:00 UTC
- [ ] Final docker compose test
- [ ] Demo URL loads correctly
- [ ] Discord bot responds to /stats
- [ ] Landing page star counter works
- [ ] All draft posts open in browser tabs
- [ ] Coffee ready ☕
