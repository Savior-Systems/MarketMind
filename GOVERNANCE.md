# Project Governance

MarketMind is an open-source project founded under the narrative of **"Built By One. Owned By Everyone."** Our governance structure balances fast, initial execution with gradual decentralized control.

## Philosophy

We believe that AI-assisted solo developers can create complex SaaS architectures, which should subsequently be owned collectively by the community that hosts and contributes to them.

## Current Status: Benevolent Dictator For Now (BDFN)

In this initial bootstrap phase (v0.1.x), the creator and founder retains final authority over the roadmap, pull requests, and core architectural direction. This ensures that the primary Swarm architecture remains cohesive as the project builds momentum.

## Path to Community Governance

Once the project reaches **50+ contributors** with merged PRs, we will transition to a community-governed steering committee:
1.  **Steering Committee**: Elected from the top contributors.
2.  **Workgroups**: Sub-teams dedicated to specific domains (e.g., Security, Frontend, Integrations).

## Decision-Making Process

Any major architectural change must start as an **RFC (Request for Comments)** in GitHub Discussions.
*   Discussion open for 7 days.
*   BDFN / Steering Committee reviews community feedback before approving implementation.

## Star-to-Vote Roadmap System

To align the codebase with community interests, repository stargazers can vote on priority features in the roadmap using our Star-to-Vote dashboard integration.

## Conflict Resolution

In cases of disagreement, issues are escalated to steering committee mediators. Respect and constructive dialogue are mandatory.
