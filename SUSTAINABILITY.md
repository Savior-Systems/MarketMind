# MarketMind Sustainability Pact

## What We Promise (Forever)

1. **Core Features Always Free**: The core open-source product will never be feature-stripped to force paid upgrades.
2. **Self-Hosted Parity**: Features that exist in the self-hosted version will always have full parity with any future cloud version.
3. **No Data Lock-In**: Your data is always exportable. Always.
4. **MIT License Protection**: Even if development stops, anyone can fork and continue under MIT.
5. **Community Credit**: Every contributor will always be publicly credited.

## How We'll Sustain (Future)

1. **MarketMind Cloud** — Optional hosted version for non-technical users (planned $29/mo)
2. **Enterprise Support** — Priority SLA and custom integrations (planned $99/mo)
3. **GitHub Sponsors** — Individual and corporate sponsorship
4. **Training & Certification** — For agencies and marketing teams

## The Anti-Enshittification Clause

> If MarketMind ever violates promises 1–5 above, any community member can cite 
> this document as a public accountability measure. This pact is version-controlled 
> in git — we can never quietly edit it away.
