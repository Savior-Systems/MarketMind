# Security Policy

We take the security of MarketMind very seriously. Since the platform is self-hosted and handles API credentials, protecting database stores and access keys is a priority.

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue. Instead, follow one of these private channels:
*   Email a detailed report to `security@marketmind.dev`
*   Submit a private advisory via GitHub Security Advisories

## Response Time Commitment

*   **Acknowledgment**: Within 48 hours of initial report receipt.
*   **Triage & Remediation**: We commit to releasing a patch within 7 days for verified critical vulnerabilities.

## Supported Versions

Security updates are currently backported to:

| Version | Supported |
|---------|-----------|
| v0.1.x  | Yes       |

## Disclosure Policy

We follow a responsible disclosure policy. We request that you give us a 90-day window to triage and patch the issue before making details public.
