# MarketMind Discord Server Setup Guide

This guide details the layout, role architecture, and bot integration guidelines for the MarketMind Discord server community.

---

## 🏛️ Server Architecture

### 1. Categories & Channels

#### 📢 ANNOUNCEMENTS
*   `#announcements` (Read-only for users, Admin/Bot write)
*   `#star-tracker` (Read-only for users, Bot writes 6-hourly updates)
*   `#founders-log` (Read-only for users, Daily developer log)
*   `#milestones` (Read-only for users, Bot prints milestone reward unlocks)

#### 💬 COMMUNITY
*   `#general` (General conversation)
*   `#introductions` (Introduce yourself)
*   `#show-and-tell` (Show off social campaigns generated by MarketMind)
*   `#ideas-and-feedback` (Feature suggestions)

#### 🔧 SUPPORT
*   `#help` (Technical assistance; tracked by **Helper Leaderboard Bot**)
*   `#setup-guide` (Read-only, pinned setup instructions and guides)
*   `#bug-reports` (Redirect link to GitHub Issues)

#### ⭐ STARGAZERS ONLY *(Stargazer Role Required)*
*   `#stargazers-lounge` (Chat room for verified stargazers)
*   `#early-builds` (Beta builds and early releases)
*   `#prompt-templates` (Share successful system/user prompt variations)
*   `#founder-ama` (Asynchronous Ask-Me-Anything sessions with core maintainers)

#### 🏛️ FOUNDERS ONLY *(Founding Member Role Required - First 1,000)*
*   `#founders-council` (Private discussions for early adopters)
*   `#roadmap-voting` (Interactive polls determining priority backlog items)

#### 👩‍💻 DEVELOPMENT
*   `#dev-discussion` (Open source contribution debates)
*   `#contributors` (Private discussion for merged PR authors)

## 🎭 Roles Configuration

Configure roles in Discord **Server Settings -> Roles** with the following hierarchy and permission rules:

| Role Name | Color | Permissions | Requirement / Purpose |
| :--- | :--- | :--- | :--- |
| **@Moderator** | Red (`#ef4444`) | Manage Messages, Kick/Ban, Manage Channels | Dedicated community moderators |
| **@Contributor** | Green (`#10b981`) | Standard permissions | Users who have had at least one pull request merged |
| **@Community MVP** | Purple (`#a855f7`) | Standard permissions | Awarded automatically by bot to the monthly top helper |
| **@Founding Member** | Gold (`#f59e0b`) | Access to Founders category | Stargazers verified within the first 1,000 star milestone |
| **@Stargazer** | Blue (`#3b82f6`) | Access to Stargazers category | Verified GitHub stargazers (assigned via `/verify`) |
| **@everyone** | Default | Read-only in Announcement, Support, and Private rooms | General public members |

## 🤖 Bot Registration & Configuration

1. Visit the [Discord Developer Portal](https://discord.com/developers/applications).
2. Create a new Application called `MarketMind-Bot`.
3. In the **Bot** tab:
   * Enable the **Server Members Intent** (required for `on_member_join` cogs).
   * Enable the **Message Content Intent** (required for `#help` leaderboard logging).
4. Invite the bot using the OAuth2 URL Generator with the `bot` and `applications.commands` scopes, granting the following permissions:
   * **Manage Roles** (to assign `Stargazer` and `Founding Member` roles)
   * **Send Messages**, **Read Message History**, **Embed Links**
5. Setup the Discord Bot environment variables in `tools/discord_bot/.env`:
   ```env
   DISCORD_TOKEN=your_discord_bot_token_here
   MARKETMIND_API_URL=https://marketmind-backend.onrender.com/api/v1
   GITHUB_REPO=Savior-Systems/MarketMind
   GITHUB_CLIENT_ID=your_github_client_id_here
   ```
6. Start the bot:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```
